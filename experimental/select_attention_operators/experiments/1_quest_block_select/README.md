# Experiment 1 - Quest Block Select (Decoding)
This experiment checks the functional correctness and the performance of the basic implementation of quest predictor.

### Scenario parameters
 - `k` - number of the selected elements

### Test the operator first
To verify it was properly built
```bash
pytest -k basic -v  # run only basic sweep
pytest .            # run all tests
```

### Run a single scenario
To run an in-depth comparison between a kernel and its reference implementation in python:
```bash
python test_quest_block_select.py
```

### Run benchmarking
To see latency and memory bandwidth
```bash
python ./benchmark_quest_block_select.py | tee run_bench_quest_block_select.log

```
