#### 调试定位

当算子遇到精度问题时可以通过printf/DumpTensor 获取Kernel中间结果来进行调测

下方以AddExample自定义算子样例为例:
1. 使用[printf](https://www.hiascend.com/document/detail/zh/canncommercial/82RC1/index/index.html?sub_id=%2Fzh%2Fcanncommercial%2F82RC1%2FAPI%2Fascendcopapi%2Fatlasascendc_api_07_0193.html)打印当前核计算Block长度
```c++
blockLength_ = tilingData->totalLength / AscendC::GetBlockNum();
tileNum_ = tilingData->tileNum;
tileLength_ = blockLength_ / tileNum_ / BUFFER_NUM;
AscendC::PRINTF("Tiling blockLength\n", blockLength_);
```
2. 使用[DumpTensor](https://www.hiascend.com/document/detail/zh/canncommercial/82RC1/index/index.html?sub_id=%2Fzh%2Fcanncommercial%2F82RC1%2FAPI%2Fascendcopapi%2Fatlasascendc_api_07_0192.html) Dump输出Tensor。
```c++
AscendC::LocalTensor<T> zLocal = outputQueueZ.DeQue<T>();
DumpTensor(zLocal, 0, 128);
AscendC::DataCopy(outputGMZ[progress * tileLength_], zLocal, tileLength_);
```

3. 对于复杂场景，比如算子卡死，GM/UB访问越界等场景，可以采取单步调试，具体细节请参见算子调测工具[msdebug](https://www.hiascend.com/document/detail/zh/mindstudio/81RC1/ODtools/Operatordevelopmenttools/atlasopdev_16_0062.html)。

#### 性能调优

算子性能调优主要是通过采集算子上板运行时的实际各项流水指标来分析当前算子Bound场景。

下方以AddExample自定义算子样例为例:

当前样例使用方式是aclnn调用，使用[msprof](https://www.hiascend.com/document/detail/zh/canncommercial/82RC1/index/index.html?sub_id=%2Fzh%2Fcanncommercial%2F82RC1%2Fdevaids%2FProfiling%2Fatlasprofiling_16_0010.html)进行采集性能

1. 在上述测试样例编译完成后，进入到`ops-transformer-dev/example/add_example/examples/eager_mode/build/bin`目录中
2. 执行`msprof op ./test_aclnn_add_example`
之后会在`build/bin/OPPROF_*`下生成具体的Profiling文件，采集完成后会打屏显示如下信息：

``` text
Op Name: AddExample_a1532827238e1555db7b997c7bce2928_high_performance_1
Op Type: vector             
Task Duration(us): 97.861954 
Block Dim: 8
Mix Block Dim:
Device Id: 0
Pid: 2776181
Current Freq: 1800
Rated Freq: 1800
```

其中Task Duration是当前算子Kernel耗时，Block Dim是当前算子执行核数。

算子内部各项流水详细指标可以着重关注`OPPROF_*`下的`ArithmeticUtilization`文件，其中包含当前各项流水的占比，详细性能字段可参考[ArithmeticUtilization字段描述](https://www.hiascend.com/document/detail/zh/canncommercial/82RC1/index/index.html?sub_id=%2Fzh%2Fcanncommercial%2F82RC1%2Fdevaids%2Foptool%2Fatlasopdev_16_0093.html)。
